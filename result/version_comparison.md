## v5 最优参数

```python
# 止盈参数
upper_mult = 2.5          # 止盈宽度倍数
macd_high_thresh = 0.8    # 强趋势阈值 (MACD > macd_highest × 0.8)
macd_low_thresh = 0.4     # 中趋势阈值 (MACD > macd_highest × 0.4)
macd_high_factor = 0.3    # 强趋势止盈倍数 (std_scale × 0.3)
macd_low_factor = 0.6     # 中趋势止盈倍数 (std_scale × 0.6)

# 分批止盈参数
profit_threshold = 8.0    # 盈利 8% 时触发分批止盈
sell_pct = 30.0           # 卖出 30% 仓位
```

## 止盈公式

```python
std_scale = (current_price - lowest_12) × 2.5

if MACD > macd_highest × 0.8:      # 强趋势 → 小目标
    target = price + std_scale × 0.3
elif MACD > macd_highest × 0.4:    # 中趋势 → 中目标
    target = price + std_scale × 0.5
else:                               # 弱趋势 → 满目标
    target = price + std_scale × 1.0
```

## v7 分析

v7 在 v5 基础上加了 `max_loss_pct = -15.0` 硬性百分比止损，但结果全面退步：

| 指标 | v5 | v7 | 变化 |
|------|----|----|------|
| 平均收益 | +42.22% | +41.86% | ↓ -0.36% |
| 盈利数 | 30/36 (83%) | 28/36 (77.8%) | ↓ -5.2% |
| 夏普 | 1.03 | 0.80 | ↓ -0.23 |
| 最差损失 | -25.15% | -25.15% | = 无变化 |

**原因**：
1. InOutLine 的 12 期最低价动态止损已比 -15% 更紧，固定百分比止损在多数据情况下不会先触发
2. 最差损失 -25.15% 的股票是单日跳空大跌，开盘直接越过 -15%，硬止损来不及在 -15% 处执行，最终损失不变
3. 硬止损在部分震荡行情中提前斩仓，降低了整体收益率


## v8 分析

v8 在 v5 基础上加入 ATR 移动止损（3.5×ATR），目标是兼顾收益和回撤控制：

| 指标 | v5 | v8 (3.5×ATR) | v6 (3.0×ATR) |
|------|----|-------------|-------------|
| 平均收益 | +42.22% | +32.78% | +27.06% |
| 盈利数 | 29/36 (81%) | 27/36 (75%) | 28/36 (78%) |
| 夏普 | 1.03 | 0.72 | 0.83 |
| 最高收益 | +143.66% | +97.90% | +111.13% |
| 最低收益 | -25.15% | -10.31% | -17.37% |

**发现**：
1. ATR 移动止损确实有效控制尾部风险：最低损失从 -25.15% 降至 -10.31%，大幅优于 v6 的 -17.37%
2. 但 3.5×ATR 仍然太紧，扫掉了正常回调中的仓位，平均收益下降 9.44%
3. 头部收益从 +143.66% 降至 +97.90%，说明 ATR 止损在强趋势股上过早退出
4. 夏普从 1.03 降至 0.72，收益降低幅度大于波动率降低幅度
5. 相比 v6 的 3.0×ATR (27.06%)，3.5×ATR 有边际改善，但离 v5 的 42% 仍有差距

**下一步**：尝试更宽的 ATR 倍数（5.0-6.0），或改用基于百分比利润的动态 ATR 倍数（盈利越多、止损越紧）。
